# Metodología Juego - Guess Who? (¿Quién es Quién?)

Este es un juego interactivo de "Adivina Quién" adaptado para aprender sobre agentes infecciosos, transmisión y prevención.

## Características

- **Modo 1vs1**: Juega contra otro jugador (o la máquina simulada).
- **Modo Aula vs Profe**: Modo para jugar en clase.
- **Categorías**: Agente, Transmisión, Prevención Ciudadana, Prevención Hospitalaria, Sistema Afectado.
- **Interactividad**: Cartas giratorias, eliminación visual (X), y overlays informativos.

## Instalación

1. Clona el repositorio.
2. Instala las dependencias:

```bash
npm install
```

## Uso

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

Abre tu navegador en `http://localhost:5173`.

## Tecnologías

- Vanilla JavaScript
- Vite
- CSS3 (Variables, Grid, Flexbox, 3D Transforms)
